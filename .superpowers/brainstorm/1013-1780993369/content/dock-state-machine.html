Dock 显隐状态机 — 新设计

核心改动：3秒隐藏延迟 + Win键冷却 + 系统UI过滤

状态转换图

🟢 常驻 (Docked)

Dock 可见，置顶，无键盘钩子

条件：dock 所在屏幕无全屏窗口

⬇️ ⬆️
⬇ 检测到全屏 → 启动 3s 计时器
⬆ 3s 内全屏消失 → 取消计时，保持常驻

🔴 隐藏 (Hidden)

Dock 不可见，键盘钩子+底部边缘轮询激活

条件：全屏确认持续 ≥ 3 秒

⬆️
⚠️ Win键 / 鼠标触底 → 立即显示
⚠️ 全屏窗口关闭 → 立即显示

🛡️ 防冲突机制

⏱ 3秒隐藏延迟
开始菜单、通知中心等短暂弹出不会误触发隐藏
❄️ Win键冷却 (1.5s)
Win键唤醒后 1.5s 内忽略全屏检测，避免开始菜单导致的立即回藏
🔍 系统UI过滤
全屏检测排除已知系统窗口类名，减少误判
🖥️ 屏幕感知
仅检查 dock 当前所在屏幕，副屏全屏不隐藏主屏 dock

完整事件时序

✅ 正常全屏（如视频播放器、游戏）
t=0.0s 全屏检测触发 → 启动 3s 隐藏计时器
t=3.0s 计时器到期，全屏仍存在 → Dock 隐藏
t=10s 用户关闭全屏 → 全屏检测清空 → Dock 立即显示
🛡️ 开始菜单冲突（旧逻辑bug → 新逻辑修复）
t=0.0s 用户按 Win键 → Dock 立即显示 + 启动 1.5s 冷却
t=0.1s 开始菜单弹出 → 全屏检测误触发
→ 🚫 冷却期内，忽略全屏信号
→ 🚫 系统UI类名过滤，不认为是全屏
t=0.5s 用户关闭开始菜单
t=1.5s 冷却结束，恢复正常检测 → Dock 保持常驻 ✓
⚠️ 边缘情况：Win键 + 已有全屏
Dock隐藏中，用户按 Win键 + 开始菜单弹出
→ Dock显示，冷却 1.5s
→ 1.5s 后检测到原全屏仍在 → 重新启动 3s 延迟
→ 3s 后确认全屏持续 → Dock 再次隐藏 ✓

实现涉及文件

  • DockManager — 新增 3s 隐藏计时器 + 1.5s Win键冷却计时器 + 屏幕感知
  • SysHelper::hasMaximizedOrFullscreenWindowOnMonitor — 新增系统UI窗口类过滤
  • DockWindow — 底部边缘检测改用 screen->geometry()
  • WindowPreviewPanel — 缩略图 DPI 缩放修复
  • DockItem — 运行指示器：单窗口 → 光晕小点，多窗口 → 小横条
