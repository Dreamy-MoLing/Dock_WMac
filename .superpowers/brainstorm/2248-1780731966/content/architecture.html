方案 C 整体架构变更

绿色 = 新增/重构组件，橙色 = 修改，灰色 = 不变

修改涉及 5 个组件

🆕 ClickStateMachine （新文件）
点击行为状态机 — 取代 DockWindow::handleSingleClick
状态: NoWindows / Minimized / Active / Inactive
动作: Launch / Restore / Minimize / Activate
🆕 WindowCache （新文件）
进程名 → HWND 列表缓存，解决多进程应用匹配
定期刷新 + 按需查询，替代每次 EnumWindows
✏️ IconProvider （修改）
新增 UWP/AppX 图标提取 + ExtractIconEx 回退
修复极小缩略图 + 模糊问题
✏️ WindowPreviewPanel （修改）
DWM peek（桌面临时置顶预览）
多窗口缩略图布局优化
鱼眼动画联动（悬停预览时保持放大）
✏️ DockWindow （修改）
对接 ClickStateMachine + WindowCache
悬停预览期间锁定鱼眼放大状态

数据流

DockItem 点击 → ClickStateMachine → 查询 WindowCache → 执行动作
鼠标悬停 DockItem → DockWindow 锁定鱼眼 → WindowPreviewPanel
悬停缩略图 → DWM Peek（临时窗口置顶 + 其他窗口透明）
ProcessMonitor tick → 更新 WindowCache
