转移表

状态 判定条件 点击动作 目标状态
S0 NoWindows 进程不在运行 LaunchApp() 等待 PM 确认
S0.5 BackgroundRunning 进程运行中 && 无可见窗口 && 无最小化窗口 ShowHiddenWindow() S2 / S3
S1 AllMinimized 有窗口 && 全部 IsIconic RestoreLastActive() S2
S2 ForegroundActive 有可见窗口 && 一个为前台 MinimizeAll() S1
S3 BackgroundVisible 有可见窗口 && 非前台 BringToForeground() S2

S0.5 ShowHiddenWindow 策略

1. 查找应用下 所有顶层窗口（包括不可见的，不用 IsWindowVisible 过滤）
2. 排除 WS_EX_TOOLWINDOW（托盘图标窗口本身）
3. 优先用 最后一个被激活的窗口（记录 Z-order 或上次激活时间）
4. ShowWindow(SW_SHOW) + SetForegroundWindow
5. 如果确实找不到任何窗口 → fallback LaunchApp()（纯托盘无窗口应用）

判定伪代码

bool processRunning = ProcessMonitor::isRunning(appId);
bool hasVisible     = WindowCache::hasVisibleWindows(wmClass);
bool hasMinimized   = WindowCache::hasMinimizedWindows(wmClass);
bool hasHidden      = WindowCache::hasHiddenWindows(wmClass);  // 不可见非最小化
bool isForeground   = WindowCache::isForegroundApp(wmClass);

State state;
if (!processRunning)                             state = S0_NoWindows;
else if (!hasVisible && !hasMinimized && hasHidden) state = S0p5_BackgroundRunning;
else if (!hasVisible && hasMinimized)            state = S1_AllMinimized;
else if (hasVisible && isForeground)             state = S2_ForegroundActive;
else if (hasVisible && !isForeground)            state = S3_BackgroundVisible;
