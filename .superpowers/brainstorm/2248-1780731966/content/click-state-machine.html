ClickStateMachine — 点击状态转移

取代 DockWindow::handleSingleClick 的 if-else 分支，4 状态 + 4 转移

状态定义（由 WindowCache 查询结果判定）

S0

NoWindows

应用未启动，或进程在运行但无可见顶层窗口

S1

AllMinimized

有窗口，但全部处于 SW_MINIMIZE 状态

S2

ForegroundActive

当前前台激活窗口属于此应用

S3

BackgroundVisible

有可见窗口，但非当前前台焦点

点击转移（4 条边）

S0 NoWindows → LaunchApp()
QProcess::startDetached + 等待 ProcessMonitor 确认运行

S1 AllMinimized → RestoreLastActive()
ShowWindow(SW_RESTORE) + SetForegroundWindow → 进入 S2

S2 ForegroundActive → MinimizeAll()
遍历应用所有窗口 ShowWindow(SW_MINIMIZE) → 进入 S1

S3 BackgroundVisible → BringToForeground()
AllowSetForegroundWindow + SetForegroundWindow(lastActiveHwnd) → 进入 S2

状态判定逻辑

bool hasAnyWindow    = WindowCache::hasWindows(wmClass);
bool allMinimized    = WindowCache::allMinimized(wmClass);
bool isForeground    = WindowCache::isForegroundApp(wmClass);

State state;
if (!hasAnyWindow)              state = NoWindows;
else if (allMinimized)          state = AllMinimized;
else if (isForeground)          state = ForegroundActive;
else                            state = BackgroundVisible;

DoubleClick：永远走 Launch 路径（不变）

双击行为维持现有一致：无论当前状态，始终 QProcess::startDetached 启动新实例。
